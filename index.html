FE-XicoOS and its apps

FE-Xico UpdateR and FE-Xico Doctor are separate repositories, and both are built into every FE-XicoOS image.

FE-XicoOS

Private repository RoYoshi/FE-Xico. Its source isn't public.

An independently built Linux desktop on Fedora, for gaming, customising and a desktop with a look of its own. The whole system updates as one image (Fedora bootc), so an update either applies completely or not at all, and the previous version stays one restart away.

It runs KDE Plasma 6 and is in active development on Fedora 45. It is not a supported release yet.

  • FE-Xico Aurora, one theme for the whole desktop: Plasma style, colours, icons, sounds, login screen, boot splash and wallpapers, in black with green and magenta
  • LaunchX, an optional application launcher of its own, next to KDE's
  • Gaming tools: Steam, MangoHud, vkBasalt, Gamescope and ProtonPlus
  • Everyday apps: Dolphin, Foot, LibreWolf, Bazaar, Bottles, Haruna, nomacs, Papers and Notepad Next
  • Flatpak, Distrobox, Podman and Homebrew for installing more

  • FE-Xico UpdateR

    Private repository RoYoshi/FE-Xico-UpdateR. Its source isn't public.

    The update app of FE-XicoOS, being written from scratch in C++ and Qt Quick. It checks for, downloads and rolls back FE-XicoOS updates, and shows the release notes, the update history and the technical details, in words anyone can follow.

    It replaces the earlier updater based on Bazzite Updater by Robert French and contributors, which is kept as FE-Xico-UpdateR-olddy.

  • FE-Xico Doctor

    Public repository RoYoshi/Doctor

    A health check for FE-XicoOS. It looks at the parts of the system that tend to go wrong (updates, services, graphics drivers, controllers, storage, Flatpaks, network and logs) and says what each finding means and what you can do about it.

    It only looks: it never needs root, never changes anything, never goes online and never uploads anything. Reports can be shared with personal details such as names, addresses and keys replaced.

A horror game

The Far Backrooms

Private repository RoYoshi/backroomsproject. Its source isn't public.

A browser-first multiplayer survival-horror game, and a love letter to internet horror as a whole, with The Backrooms as its poster child. You wander the yellow rooms of Level 0 while the Hound and the Smiler hunt you, and everyone in a session meets the same monsters.

The browser draws the level with PixiJS, and a Node.js server runs the monsters and connects the players. It is in active development, built in stages; the current one, 2F, gives the monsters shared intelligence that works only from what they have actually seen.

The server may know the truth, but a monster may only act on what it has actually seen or heard.

The one rule every monster follows

Who hunts you

  • The HoundHunts with the pack: since stage 2F, what one has actually seen, the others can act on.
  • The SmilerA grin in the dark, straight from the Backrooms canon. Keep the lights on.

How it's built

  • Built for the browser, phones and low-end computers included
  • Everyone in a session meets the same monsters, run by one Node.js server
  • One server so far, in US Central, with more locations planned
  • Every candidate build is tested by a QA team before it ships

Made by RoYoshi (programming, game, level, graphic and web design) and ₘₐᵣᵢᵢₖᵧᵤ (creative direction, music, sound, QA and community).
